🛒 BigBasket – Django eCommerce Web Application

BigBasket is a full-stack eCommerce web application built using Django.
It allows users to browse grocery products, add items to the cart, and manage orders with a smooth and responsive interface.
The project follows Django’s MVT architecture and integrates database management using SQLite.
It demonstrates backend development, authentication, dynamic templates, and real-world eCommerce functionality.

🚀 Features
User Registration & Login
Product Listing & Categories
Add to Cart System
Order Management
Admin Dashboard for Product Control
Media & Static File Handling

🛠️ Tech Stack
Python
Django
HTML5
CSS3
Bootstrap
SQLite

Project Structure
Ecommerce-Website/
│
├── myapp/          # Main application logic
├── templates/      # HTML templates
├── static/         # CSS, JS, images
├── media/          # Uploaded product images
├── db.sqlite3      # Database file
├── manage.py       # Django project manager

🎯 Project Objective
This project was developed to practice full-stack web development using Django and to simulate a real-world online grocery shopping platform similar to BigBasket.
